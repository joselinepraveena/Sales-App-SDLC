# Security and DevSecOps

- Threat-model trust boundaries, payment flows, administrative functions, partner APIs, and events
- Least privilege for people, pipelines, managed identities, and Kubernetes service accounts
- GitHub Advanced Security: CodeQL, secret scanning with push protection, dependency review, Dependabot
- Scan source, dependencies, images, Helm, and Terraform with a single ownership model
- Retain SBOM, signed provenance, scan evidence, approvals, and deployed digest records
- Pod Security Admission, NetworkPolicy, admission policy, allowed registries, signature verification
- Runtime alerts: Defender for Containers and Microsoft Sentinel
- Payment-card data stays with the provider; this platform stores token references only and still requires a formal PCI DSS assessment before handling in-scope data
