# Resilience, backup, and disaster recovery

- Define RTO and RPO per capability
- Deploy AKS and data services across availability zones
- Retry with jitter, timeouts, circuit breakers, bulkheads, and bounded queues
- Test Service Bus dead-letter recovery without duplicate business outcomes (idempotency keys)
- Back up databases, Key Vault recovery settings, GitOps configuration, and platform metadata
- Active/passive multi-region by default unless the business case justifies active/active
- Run restore, failover, and regional recovery exercises
